# Morrow Market

A simulated marketplace storefront built with plain HTML, CSS, and JavaScript. No build step, no dependencies.

## Run locally

```bash
npm start
```

Then open http://localhost:4173.

## Structure

- `index.html` — storefront markup
- `styles.css` — base layout and components
- `routes.css` — page-level view styles
- `app.js` — catalog data, filtering, cart, and checkout simulation
- `server.js` — minimal static file server used by `npm start`
